# Provenance

The agent-facing method comes from [joelhooks/rat-stack](https://github.com/joelhooks/rat-stack): a short vision, repo law, contextual skills, and principles tied to source and checks.

Reference reviewed on 2026-10-17 at commit [`c0a48deb155c798bf7e3ff0352f6d5cda3b2beed`](https://github.com/joelhooks/rat-stack/tree/c0a48deb155c798bf7e3ff0352f6d5cda3b2beed): `VISION.md`, `AGENTS.md`, and the `uncomplect`, `keep-or-cut`, `learn-alchemy`, `add-a-capability`, and `test-behaviour` skills.

The text in this directory is original to alchemy-celld. No rat-stack skill was copied or vendored. Its application-specific paths, contracts, and tooling are not this provider's API. Here, uncomplect is the parent skill; each principle describes one concrete separation and its enforcement limit.

The provider's Linux and release code adapts [taslabs-net/homeflare-kit](https://github.com/taslabs-net/homeflare-kit) at `cf20298`. Code attribution and MIT terms remain in `LICENSE-homeflare-kit`; this note does not replace that notice.
